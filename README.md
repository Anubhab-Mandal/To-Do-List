# To-Do-List
Beginner MERN Stack To-Do List application built to practice full-stack development, Git, and GitHub.

# Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage with MongoDB
- Responsive user interface
- RESTful API architecture


This is a beginner MERN stack To-Do List application created as part of my learning journey. The project was built by following tutorials and implementing concepts to practice full-stack development, Git, and GitHub workflows.
